# Paper Kite Manor (UNOFFICIAL) — NeoForge 1.21.1

An unofficial NeoForge port of Paper Kite Manor for Minecraft 1.21.1. It ports Paper Kite Manor's placeable food, furniture, plants, crafting, and small creatures while adapting the project to NeoForge 1.21.1.

## Original project and attribution

- Original project by KaziCat, with code copyright held by MasterMarisa.
- CurseForge: https://www.curseforge.com/minecraft/mc-mods/paper-kite-manor
- Modrinth: https://modrinth.com/mod/paper_kite_manor
- Upstream source: https://github.com/MasterMarisa/PaperKiteManor

The upstream listings currently identify Minecraft 1.20.1 Forge. This port targets Minecraft 1.21.1 NeoForge.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Java 21
- GeckoLib 4.9.3 or newer

Jade, JEI, and Ponder are optional integrations.

## Build

Run gradlew.bat build on Windows. The release JAR is written under build/libs/.

## Verification

The port compiled and packaged successfully. Its JAR was loaded in an isolated NeoForge 1.21.1 dedicated server, which loaded the mod and saved a test world cleanly. No client rendering or full in-game feature test is claimed.
